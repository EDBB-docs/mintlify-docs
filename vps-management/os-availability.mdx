<span id="operating-system-availability" />
<span id="summary" />

EDBB offers Linux and Windows images during ordering and in the control panel. The order form has a shorter selection; **Installation → Automated Installers** also includes older images and additional choices.

Check the selector for your VPS before choosing a version. An image being available does not mean it still receives vendor security updates. For a new deployment, choose a supported release that meets your application's requirements.

## Linux images

| OS family | Order and reinstall images | Additional reinstall choices |
| --- | --- | --- |
| <span id="debian" /><span id="debian-2" />Debian | 13, 12, 11 | Check the current selector. |
| <span id="ubuntu-lts" /><span id="ubuntu-lts-2" />Ubuntu | 24.04, 22.04, 20.04 | Older 18.04 and 16.04 images may be available for compatibility. |
| <span id="almalinux" /><span id="almalinux-2" />AlmaLinux | 9, 8 | Check the current selector. |
| <span id="rocky-linux" /><span id="rocky-linux-2" />Rocky Linux | 10, 9 | Check the current selector. |
| <span id="centos-stream" /><span id="centos-/-centos-stream" />CentOS Stream | 10, 9 and legacy 8 | Legacy CentOS 7 may be available. |
| <span id="arch-linux" /><span id="arch-linux-2" />Arch Linux | Available snapshot | Additional archived snapshots. |

These are image choices, not a recommendation to use an unsupported release. Check the OS vendor's lifecycle and update the installed system before putting it into service.

## Windows images

Windows Server **2025, 2022 and 2019** evaluation images are listed for automated installation. The control panel also offers Windows 10/11 evaluation choices where available.

Evaluation media do not include a paid production licence. Check your chosen edition's requirements and licence terms. See [Windows evaluation and activation](/misc/windows-server-evaluation).

## Why are the lists different?

The shopping cart makes it easier to choose an initial system. The reinstall selector keeps additional images for compatibility and recovery needs. Use **Services → your VPS → Installation → Automated Installers** to see the choices for your service.

<Warning>
  Reinstalling an image erases the existing VPS disk. Back up your files before changing operating systems. See [reinstall your VPS](/vps-management/reinstall-vps) for the full procedure.
</Warning>

## Install a different system

| Method | When to use it |
| --- | --- |
| Automated Installers | Install one of the supplied Linux or Windows images. |
| <span id="-cloud-init" />Custom Image / Cloud-Init | Install a compatible qcow2 image and configure its first boot. Follow [Cloud-Init installation](/vps-management/cloud-init-vps-installation). |
| <span id="-manual-vnc-/-iso-installation" />ISO Boot | Run a compatible installer through the console. Use an available ISO or [request a custom ISO](/vps-management/bring-your-own-iso). |

Check that a custom image supports the VPS architecture, boot mode, disk and network drivers. Cloud-Init configures a compatible image; it does not convert an incompatible OS into a bootable one.

## ISO and recovery media

ISO images are separate from automated installers. The **Installation → ISO Boot** selector shows the current media for your VPS.

| Media | Purpose |
| --- | --- |
| Linux and appliance installers | Manual installation; the listed ISO may be an older fixed version. |
| Windows Server evaluation ISOs | Manual Windows installation. A Windows Server 2016 ISO may be listed even though it is not in the automated-install list. |
| SystemRescue 10.02 | Inspect and recover an existing Linux installation. See [Linux rescue](/vps-management/linux-rescue). |
| `1_Password-Reset-Helper.iso` | Follow the [Linux](/vps-management/reset-root-password) or [Windows](/vps-management/reset-windows-password) password-reset procedure. |

Do not format or reinstall the disk when the aim is to recover existing data. After using rescue media, unmount the ISO and boot from the local disk. See [mount and unmount an ISO](/vps-management/mount-iso-image).
