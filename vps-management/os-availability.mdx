## Installation methods

| Method | Purpose |
| --- | --- |
| Automated Installers | Install a supplied Linux or Windows image |
| Custom Image | Install a compatible qcow2 image with Cloud-Init support |
| ISO Boot | Boot installation or recovery media through the console |

The order form can show a smaller selection than the panel. Availability does not mean a release still receives vendor security updates. Check the vendor lifecycle before choosing an older release for production.

## Shared image inventory reference

The shared image inventory lists Debian 13, 12 and 11; Ubuntu 24.04, 22.04 and 20.04; AlmaLinux 9 and 8; Rocky Linux 10 and 9; CentOS Stream 10, 9 and legacy 8; and Arch Linux snapshots. The broader panel inventory also lists older Ubuntu versions and CentOS 7 for compatibility.

Windows Server 2025, 2022 and 2019 evaluation images are listed, with additional Windows evaluation choices in the panel. Evaluation media do not include a production license. Use only an edition/license valid for your workload and hosting arrangement.

<span id="custom-os" />

## ISO and recovery media

The shared ISO inventory includes fixed-version installers, some older than current vendor releases. It lists **SystemRescue 10.02** and **1_Password-Reset-Helper.iso** as recovery tools. Check the actual **ISO Boot** selector before following a version-specific procedure.

A compatible custom image must support the virtual architecture, boot mode and devices presented by your VPS. Cloud-Init configures an existing compatible OS; it does not make arbitrary software or architectures bootable.

<Warning>Automated or manual installation can overwrite your disk. Back up existing data first. Recovery media should be used without formatting or reinstalling when the aim is to recover the current system.</Warning>
