Manage your VPS from the [EDBB Control Panel](https://my.edbb.com/clientarea.php). Open **Services**, select your VPS, and use this guide to find the right control.

## Meet your VPS Control Panel

The panel has three main areas:

| Area | What you will find |
| --- | --- |
| **Left: quick actions** | Power, restart and VNC console controls. |
| **Center: service tabs** | Dashboard, Installation, Traffic, Settings, rDNS, Network and Upgrades. |
| **Right: service summary** | Service details, IP addresses, Support PIN, upgrades and billing actions. |

### Power Menu

**Server On** shows that the VPS is powered on. Clicking it opens the **Power Off** confirmation. When the VPS is off, the button reads **Server Off**; click it to start the VPS.

The separate **Restart** dropdown offers:

- **Restart VPS** — restart the virtual machine; the panel indicates that VNC stays connected.
- **Power Cycle VPS** — power off, then on again; VNC disconnects.

See [Restart and power cycle](/vps-management/power-cycle-or-reboot-a-vps) for the differences, confirmation screens and startup checks.

### VNC Toggle

Open **VNC Off** to find **Enable VNC** when you need console access. Use VNC only while you need it, then disable it when you finish.

### Open Console

**Open Console** opens the browser-based console so you can follow boot or installation progress and use recovery tools. It is disabled while VNC is off, as shown above.

Follow the [VNC console guide](/vps-management/enable-vnc-server) for access instructions.

## Control Panel Highlights

### Service Summary

The right-hand sidebar identifies the selected service and shows its location, service ID, IPv4 and IPv6 details, CD-ROM state, installed OS, Support PIN and billing information. Copy buttons beside supported fields help avoid typing mistakes.

The service's **Active** badge and its runtime status are different: use **Running** or **Turned off** on the Dashboard to check whether the virtual machine is powered on.

Use the [IP settings guide](/vps-management/ip-address-information) for networking and the [Support PIN guide](/vps-management/your-support-pin) when contacting support. Keep your Support PIN out of public screenshots.

### Live Screenshot

The **Screenshot** card gives you a view of the VPS display before opening a console. Use its refresh button to request a newer preview. It can show boot messages, a login prompt, a desktop or the stopped-server screen.

The **Traffic** card shows usage as a percentage and in GB, the monthly allowance, the refill timing and the current speed status.

### Traffic Pool Ledger

The **Traffic Pool** card shows your shared reserve and Auto Hydration status. **TopUp** adds purchased traffic to the pool; it does not by itself assign that traffic to a VPS.

In the **Traffic** tab, use **Manual Hydration** and **Assign Traffic**, or select an **Auto Hydration** option. **Hydration log** shows assignments; **Pool log** shows pool activity. See the [Traffic Pool guide](/faq/traffic-bandwidth/traffic-pool) before assigning traffic.

The card lists **Additional IPs**, **Drive Size Boost**, **RAM Upgrade** and **vCPU Upgrade**. It describes configured additions to your plan; it is not a live CPU or memory usage monitor. **Upgrade Now** opens the resource-upgrade flow.

### Fast Maintenance

Below the dashboard cards:

- **Reinstall** opens Installation. Reinstalling erases existing data; [back up first](/backups), then follow the [reinstallation guide](/vps-management/reinstall-vps).
- **IP Change** opens the IP-change ordering options. Review the [IP-change guide](/faq/ip-addresses/change-ip-address) before replacing an address used by your services.

## Tabs for Installation - Networking

| Tab | Use it for | Detailed guide |
| --- | --- | --- |
| **Dashboard** | Check status, resources, display preview, traffic and configured options. | The dashboard tour above. |
| **Installation** | Choose **Automated Installers**, **Custom Image** or **ISO Boot**. | [Reinstall](/vps-management/reinstall-vps), [custom images](/vps-management/bring-your-own-iso), [mount ISO](/vps-management/mount-iso-image), [Cloud-Init](/vps-management/cloud-init-vps-installation). |
| **Traffic** | View usage graphs, assign pool traffic, configure Auto Hydration and inspect logs. | [Traffic statistics](/faq/traffic-bandwidth/traffic-statistics) and [Traffic Pool](/faq/traffic-bandwidth/traffic-pool). |
| **Settings** | Adjust boot timeout, BIOS/UEFI, TPM, CPU layout, drivers, VNC keymap and description. | [Hardware settings](/vps-management/system-configuration-dialog) and [boot mode](/vps-management/efi-vs-bios-and-tpm). |
| **rDNS** | Manage PTR records for reverse DNS. | [Reverse DNS](/faq/ip-addresses/reverse-dns). |
| **Network** | Find assigned addresses, subnet/prefix information, gateways and resolver guidance. | [IP settings](/vps-management/ip-address-information) and [IPv6 configuration](/vps-management/ipv6-configuration). |
| **Upgrades** | Choose **Upgrade Your Plan** or **Upgrade Now** for individual components. | [Upgrade options](/faq/upgrades-downgrades/upgrades). |

Settings changes can affect boot and connectivity. Read the relevant guide before applying them. Additional IP addresses also need configuration inside the operating system; the **Network** tab provides the values to use.
