<span id="system-configuration-overview" />

The **Settings** tab controls how virtual hardware is presented to your VPS. Record the current configuration before making a change and plan a maintenance window.

<span id="important-considerations" />

<Warning>
Changing disk/network drivers or boot mode can prevent startup or remote access. Verify guest driver support, keep backups and a console recovery path, and store encryption recovery keys before changing vTPM settings.
</Warning>

<span id="how-settings-are-applied" />
<span id="key-settings" />

<span id="accessing-the-dialog" />

## Open Settings

Select the VPS in the [EDBB Control Panel](https://my.edbb.com/clientarea.php), then open **Settings**.

<Frame>
![EDBB Settings tab showing boot, CPU, display, driver and identification controls](/assets/settings.png)
</Frame>

## Review the available controls

| Control | Purpose and caution |
| --- | --- |
| Boot Menu Timeout | Time available to select a boot device |
| CPU Model | Model exposed to the guest; host passthrough exposes host features but can affect migration compatibility |
| CPU cores vs sockets | Virtual topology; check guest and application limits, not assumptions about physical core ownership |
| Video Driver | Guest display adapter; choose a driver supported by the OS |
| Disk Driver | Storage controller; install the guest driver before switching |
| Network Driver | Virtual NIC; switching can change guest interface behavior |
| VNC Keymap | Console keyboard interpretation; test special characters before changing passwords |
| Description | Service label; changing it does not rename an already installed guest OS |

<span id="-boot-mode-and-tpm" />

Boot mode and vTPM options, where exposed for your service, must match your image and recovery requirements. See [boot mode and TPM](/vps-management/efi-vs-bios-and-tpm). UEFI does not by itself establish that Secure Boot is enabled.

<span id="apply-changes" />

## Apply and verify

Review the changes and select **Apply**. Follow the required [full power-cycle procedure](/vps-management/power-cycle-or-reboot-a-vps) for hardware changes, then verify boot, networking and applications through the console before closing it. If a setting is absent, ask support rather than assuming an EDIS Global panel workflow applies.
