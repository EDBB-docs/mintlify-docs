## Reinstall from the Installation Tab

Reinstalling replaces the operating system on your existing VPS. Open **Services**, select the VPS, then choose **Installation → Automated Installers**.

<Warning>
  Reinstalling permanently erases the VPS disk. Back up your data before continuing. Treat **Start the installation** as the destructive action; do not expect a separate confirmation screen.
</Warning>

The example uses Debian. Select the Windows tile for a Windows Server installation. Available versions depend on the selected OS family.

## Install the operating system

<Steps>
  <Step title="Select the operating system">
    Click an OS family tile, such as Debian, Ubuntu or Windows. Then choose the required release in **Version**.
  </Step>
  <Step title="Prepare access credentials">
    Set a strong password and store it securely. For Linux, the panel also provides an optional **SSH-RSA** public-key field. Never paste a private key there.

<Frame caption="Check the version and save your credentials before starting. The password stays masked.">
  <div style={{ background: "#0b1830", padding: "24px", borderRadius: "12px", borderTop: "3px solid #14b8a6" }}>
    <img src="/assets/vps-guides/reinstall-credentials.png" alt="Debian version selector, masked password, optional SSH-RSA field and Start the installation button" />
  </div>
</Frame>
  </Step>
  <Step title="Start the reinstall">
    Check that you selected the correct VPS and have a backup, then click **Start the installation**. The installer replaces the disk contents and starts the VPS automatically.

    A reinstall does not send a new welcome email. Use the credentials you specified for the new Linux root or Windows Administrator account.
  </Step>
</Steps>

## Track Progress - then Connect

The Installation tab shows a waiting message while the selected operating system is being installed. Power controls may be temporarily disabled.

<Frame caption="During installation, wait for the automated process to finish.">
  <div style={{ background: "#0b1830", padding: "24px", borderRadius: "12px", borderTop: "3px solid #14b8a6" }}>
    <img src="/assets/vps-guides/reinstall-progress.png" alt="Please wait, Debian Trixie (13) is being installed message" />
  </div>
</Frame>

| Operating system | Installation time | Connect afterward |
| --- | --- | --- |
| **Linux** | Up to **5 minutes** | [SSH](/linux-secure-shell-ssh) with your new credentials. |
| **Windows** | Up to **15 minutes** | [Remote Desktop](/windows-remote-desktop) as Administrator with your new password. |

<Warning>
  Do not power off, restart or power cycle the VPS during installation. The installer handles the required restarts. SSH/RDP access is unavailable until installation finishes.
</Warning>

When the waiting message clears, return to **Dashboard** and check **Status**. Refresh the **Screenshot** preview to see boot progress or the login screen.

**Running** alone does not prove that SSH, RDP or applications are ready. Try your normal connection after installation finishes. If access still fails after the installation window, use the [VNC console](/vps-management/enable-vnc-server) and [connectivity guide](/faq/ip-addresses/network-is-down).
