---

EDBB uses infrastructure from the EDIS Global resource pool. The shared [status page](https://status.edis.global/) is the intentional infrastructure status resource for EDBB.

Check the relevant location and incident updates. Use subscription options offered on that page if you want notifications. A clear status page does not rule out an issue with your VPS or application.

If you still need help, contact [support@edbb.com](mailto:support@edbb.com) with the service IP, timestamp and timezone, symptoms and the checks you have performed. See [support scope](/how-our-support-team-helps-you).
