title: "Check infrastructure status"
sidebarTitle: "Infrastructure status"
description: "Check the shared EDIS Global status page for infrastructure incidents affecting EDBB locations, and provide useful evidence when contacting support."
---

EDBB uses infrastructure from the EDIS Global resource pool. Check the shared [status page](https://status.edis.global/) for incidents and maintenance affecting your VPS location.

Open your location to read the latest updates. You can subscribe to notifications on the status page. If no incident is listed, your server or application may still need troubleshooting.

If you still need help, contact [support@edbb.com](mailto:support@edbb.com) with the service IP, timestamp and timezone, symptoms and the checks you have performed. See [support guide](/how-our-support-team-helps-you).
