<span id="why-ssh-matters" />

SSH provides an encrypted terminal connection to your Linux VPS. You need the assigned IP, a valid username and the password or key configured for that installation.

<span id="connect-to-your-vps" />

## Connect

1. Open a terminal with an SSH client on your computer. If Windows lacks the client, install the supported OpenSSH Client optional feature.
2. Replace the documentation-only address below with your VPS IP and use the correct account:

```bash
ssh root@192.0.2.10
```

3. Before accepting a new host key, compare the shown fingerprint with the server's key through the trusted [VNC console](/vps-management/enable-vnc-server). For an Ed25519 host key, inspect it on the server with:

```bash
ssh-keygen -lf /etc/ssh/ssh_host_ed25519_key.pub
```

4. Authenticate with your password or key. A successful connection opens the remote shell. Type `exit` to disconnect.

An unexpected changed host key needs investigation; do not suppress the warning automatically. A reinstall normally generates new host keys, which you can verify through the console.

<span id="quick-safety-checks" />

## Secure ongoing access

Create and test a normal administrative user with SSH-key access. Verify a second login and sudo before disabling root or password authentication. A key plus an optional password is not automatically two-factor authentication.

Follow [SSH hardening](/getting-started/ssh-security-hardening), keep packages updated and retain a console recovery path before firewall changes.
