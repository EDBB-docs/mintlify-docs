## Connect to Your Windows VPS

<Info>
  Remote Desktop Protocol (RDP) delivers full graphical control of your Windows VPS. Bring the server’s IPv4 address, the <code>Administrator</code> password you set in the portal, and a stable network connection.
</Info>

Need to deploy Windows first? Reinstall from the EDBB Control Panel with the <a href="/vps-management/reinstall-vps">OS reinstall guide</a>.

---

## Why Use RDP


###  Full Desktop

Interact with the VPS as if you were sitting in front of the console—perfect for GUI apps, MMC tools, and quick configuration checks.


###  Secure Transport

RDP supports encrypted transport; verify the server identity and keep the client and server updated. Combine it with the portal’s one-time console access for password resets or emergency recovery.


###  Cross-Platform Clients

Microsoft ships native clients for Windows and macOS, and open-source alternatives exist for Linux—use whichever device you prefer.

## Connect from Windows Desktop

<Steps>
  <Step title="Open Remote Desktop Connection">
    Press the Windows key, type <strong>Remote Desktop Connection</strong>, and launch the desktop app. Prefer a shortcut? Press <code>Win + R</code>, enter <code>mstsc</code>, then click <strong>OK</strong>.

    ![Open RDP client on Windows desktop](/assets/1sSq3fI0sZJj8Zc4RoSr4-E6s05O4r7d3ThHTglgxfu-20241202-110408.png)
  </Step>
  <Step title="Enter the VPS address">
    In the <strong>Computer</strong> field, paste the IPv4 address (or hostname) from your welcome email. Click <strong>Show Options</strong> to expand the dialogue before you connect.

    ![Enter the VPS IPv4 in the Computer field](/assets/1sSq3fI0sZJj8Zc4RoSr4-eE8Z7tBNfWJaa74qfI7Qv-20241202-112004.png)
  </Step>
  <Step title="Use the Administrator account">
    Unless you created a custom user, type <strong>Administrator</strong>. Leave “Ask for credentials every time” enabled if multiple people share the workstation.

    ![Enter Administrator as the username](/assets/1sSq3fI0sZJj8Zc4RoSr4-K1RXNa_wHwVjBcGOvTw4K-20241202-112943.png)
  </Step>
  <Step title="Connect and authenticate">
    Click <strong>Connect</strong>, enter the VPS password, and inspect the certificate prompt. Verify the server identity through a trusted source such as your VPS console before accepting an unfamiliar certificate; investigate unexpected changes.

    ![Password prompt and certificate warning](/assets/1sSq3fI0sZJj8Zc4RoSr4-AGGOxauevnKCyRuSL3vFW-20241202-113527.png)
  </Step>
</Steps>

Once authenticated, the Windows desktop loads and you can begin managing your VPS. Closing the RDP window disconnects while applications can remain running. **Start → Sign out** ends the user session and closes its applications; save work first.

## macOS Client (Microsoft Windows App)

The screenshots show an earlier Windows App release. Current versions can arrange controls differently; use the equivalent Add PC and connection settings for your installed version.

<Steps>
  <Step title="Install Microsoft Windows App">
    Download the free client (formerly Microsoft Remote Desktop) from the <a href="https://apps.apple.com/us/app/windows-app/id1295203466" target="_blank" rel="noreferrer">Mac App Store</a>.

    ![Microsoft Windows App listing in the Mac App Store](/assets/huaNpFAxK5PVCl_NLo3ID-QlQORqnbwx4sd8x4KCHOl-20241202-160326.png)
  </Step>
  <Step title="Add your VPS">
    Open the app, click the <strong>+</strong> button, choose <strong>Add PC</strong>, and enter the VPS IPv4 address. Give it a friendly name so you recognise it later.

    ![Add PC window showing IP entry and friendly name](/assets/huaNpFAxK5PVCl_NLo3ID-rbCU-h7FzGiJeIcW7xO1y-20241202-160642.png)
  </Step>
  <Step title="Store credentials or prompt each time">
    Select <strong>Administrator</strong> (or your custom user). Save the connection and double-click the tile to launch it.

    ![Saved connection tile ready to launch](/assets/bYb9Hny4tfRDK5FcumtQA_screenshot-2024-12-02-at-171013.png)
  </Step>
  <Step title="Approve prompts and sign in">
    Review the certificate and optional keychain-storage prompts. Verify the server identity before selecting <strong>Continue</strong>. Enter the password and you’ll land on the Windows desktop.

    ![Certificate prompt during first RDP connection on macOS](/assets/vI9GQIvvP61Ayho-Uhrnj_screenshot-2024-12-02-at-171118.png)
  </Step>
</Steps>

Pro tip: If you’re using a MacBook, enable “Fit session to window” in the connection settings for a smoother Retina experience.

![Windows desktop reached via Microsoft Windows App on macOS](/assets/huaNpFAxK5PVCl_NLo3ID-W0EeJBw1Um2ua4QWM6--f-20241202-161319.png)

## Keep RDP Secure

- Use a strong, unique Administrator password, store it in a password manager and change it if it may have been exposed.
- Use the portal VNC console to disable/enable RDP if you ever need to lock access quickly.
- Maintain Windows Updates (`Settings → Windows Update`) so security patches install promptly.

[Reset the Windows Admin Password](/vps-management/reset-windows-password)

Restrict RDP access to trusted source networks where practical and use Network Level Authentication when supported. Keep the VNC console as a recovery path before changing access rules.
