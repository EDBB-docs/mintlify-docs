KVM is a virtualization technology that lets a physical host run separate virtual machines. An EDBB KVM VPS has virtual CPU, memory, storage and network devices and runs its own supported operating system.

## What you control

You administer the operating system and applications through Linux root access or Windows Administrator access. Use the EDBB panel to install supported images, access the console and manage available virtual hardware settings.

A vCPU is a virtual processor presented to the operating system. It is not a promise of an exclusively reserved physical core. Performance depends on the workload and shared infrastructure; a host uplink specification is not guaranteed per-VPS throughput.

## EDBB capabilities and limits

- EDBB has its own VPS specifications and included traffic, with globally uniform pricing for each plan.
- Locations and operating-system availability use the EDIS Global resource pool; the EDBB panel and customer account are separate.
- There is no EDBB customer or order API, BYOIP or commercial /24-prefix offering.
- SSH, Cloud-Init and configuration-management tools can automate your operating system.
- You maintain backups, updates, firewall rules and application security. A paid disk export is separate from routine backups.
