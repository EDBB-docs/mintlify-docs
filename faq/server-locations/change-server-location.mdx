A location change replaces the VPS; it does not move the existing installation in place. EDBB VPS plan prices are the same globally, but a different location means different network paths and a new IP address.

<span id="after-24-hours" />

## During the first 24 hours

Instead of a refund, you may request a **one-time free location change within 24 hours of purchase**, keeping the same plan and billing cycle. EDBB provisions a replacement VPS with new login details and a new IP address. If needed, you may request one additional free primary IPv4 change for the replacement.

<Warning>
  Once the replacement VPS has been provisioned, the order is no longer eligible for a refund. A replacement does not transfer your installed applications or data. Back up and plan the migration before requesting the change.
</Warning>

Contact [support@edbb.com](mailto:support@edbb.com) with the service details and desired available location. See the complete [refund policy](/faq/billing-lifecycle/cancellation-and-refund-policy).

## Later migrations

Order a new VPS in your chosen [EDBB location](https://www.edbb.com/), migrate and test your applications, update DNS and monitoring, then cancel the old service when the migration is verified. Keep an independent backup and allow for overlapping billing while both services exist. Do not assume a later relocation is free.
