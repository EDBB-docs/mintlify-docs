Separate the physical VPS location from IP registration, routing and commercial geolocation. These answer different questions and may show different countries.

## Check the relevant evidence

Your EDBB service record identifies the location you ordered. Registry data describes address registration, while a GeoIP database estimates the location associated with an IP. Neither a WHOIS country field nor a PTR hostname alone proves a physical datacenter location.

IP prefixes can be routed across networks and countries. Do not infer that a prefix can never be used elsewhere solely from its size or registration. EDBB assigns addresses for the service you order; ask support about a mismatch rather than changing the network prefix inside the operating system or reinstalling.

For database errors, see [GeoIP databases](/faq/ip-addresses/geolocation-geoip-databases). For resolver or anycast questions, see [DNS and VPS location](/faq/ip-addresses/anycast-and-dns-location). For actual reachability, collect [network diagnostics](/faq/ip-addresses/diagnose-packet-loss).
