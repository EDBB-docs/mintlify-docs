title: "Are my VPS IP addresses static?"
sidebarTitle: "Static IP addresses"

Yes. Your VPS's assigned IPv4 and IPv6 addresses normally stay the same when you restart it, reinstall the operating system or upgrade the plan.

Each VPS includes a dedicated provider-assigned IPv4 address and an IPv6 allocation equivalent in size to a /64. See [IPv6 configuration](/vps-management/ipv6-configuration) for the required /48 interface prefix and address limits.

<span id="static-by-default" />

## When does an address change?

- You request a [primary IPv4 change](/faq/ip-addresses/change-ip-address).
- You [change the server location](/faq/server-locations/change-server-location), which creates a replacement VPS with new addresses.
- The service is terminated and its addresses are released. Ordering another VPS does not reserve the old addresses for you.

You can [add IPv4 addresses](/faq/ip-addresses/order-additional-ip-address) without replacing the primary address. Configure each additional address in the operating system after it has been assigned.
