Use the **Primary IPv4** row on your VPS Dashboard to request an eligible free replacement. For paid options, use **IP Change** below the Dashboard cards.

<Warning>
A confirmed replacement permanently releases the old IPv4 address. You cannot switch back to it. Prepare console access and your network changes before submitting the request.
</Warning>

## Find the IP-change controls

Sign in to the [EDBB Control Panel](https://my.edbb.com/clientarea.php), open **Services**, and select your VPS. On the **Dashboard**, the service-details card on the right contains **Primary IPv4**.

## Free IP Change

The panel offers one free primary IPv4 change within the first **24 hours after delivery**. The replacement is assigned randomly. EDBB aims to use a different /24 subnet, subject to availability.

<Steps>
  <Step title="Prepare access">
    Open the [VNC console](/vps-management/enable-vnc-server) before changing the address. Existing SSH or RDP connections to the old IP will no longer provide access after the replacement.
  </Step>
  <Step title="Open the confirmation">
    Click the **recycle icon** beside **Primary IPv4**. The adjacent copy icon only copies the current address.
  </Step>
  <Step title="Read the warning">
    Review the **Change IPv4 Address** dialog. **Close** leaves the address unchanged. Select **Change IP now** only when you are ready to release the old address and configure the replacement.
  </Step>
</Steps>

If the recycle icon is unavailable, check the delivery time and whether the free change has already been used. Contact support if eligibility is unclear. The free change applies only to the **primary IPv4**, not additional addresses.

## Paid changes

Use **IP Change** at the bottom of the Dashboard, or contact [support@edbb.com](mailto:support@edbb.com), for standard or bespoke replacement options. Confirm the affected VPS, address, eligibility and quoted price before ordering. A replacement does not guarantee a particular reputation, geolocation result or country reachability.

## Configure the new IP address

Once a replacement has been assigned, check the new address and network settings in the panel. Use the console to update the guest operating system, following the [Ubuntu](/vps-management/change-ip-ubuntu-1804-to-2404) or [Windows](/vps-management/change-ip-windows) guide where applicable.

Update any DNS records, allowlists and client connection settings that use the old address. Verify access on the new address before closing the console.

<Warning>Reinstallation is an alternative only when you deliberately want a fresh system. It erases existing data; back up first. See [Reinstall VPS](/vps-management/reinstall-vps).</Warning>
