<span id="can-vps-plans-announce-customer-prefixes" />
<span id="dedicated-server-requirements" />

No. EDBB does not offer **Bring Your Own IP (BYOIP)**, customer-owned prefix announcements or a commercial **/24-prefix product**.

EDBB VPS services use provider-assigned addresses. See [IP settings](/vps-management/ip-address-information), [additional IP addresses](/faq/ip-addresses/order-additional-ip-address) and [IPv6 configuration](/vps-management/ipv6-configuration) for the available configuration workflows.

This product restriction does not prohibit a valid `/24` subnet mask in an assigned network configuration. Always use the address, prefix and gateway shown for your VPS.
