A virtual private server (VPS) is a virtual machine with its own operating system, virtual CPU, memory, storage and IP addresses. It shares physical infrastructure with other virtual machines while letting you administer your own server.

## When a VPS is useful

A VPS can run websites, application services, development tools or permitted VPN workloads when you need control over software and configuration. Choose the [EDBB plan](https://www.edbb.com/) from measured CPU, RAM, disk and traffic needs rather than an assumed visitor-to-RAM formula.

<span id="what-you-get-with-an-edbb-vps" />

## What you are responsible for

EDBB supplies the hosting infrastructure. You install and maintain your software, apply security updates, restrict access, monitor workloads and keep independent backups. Root or Administrator access remains subject to the [AUP](/acceptable-use-policy).

EDBB uses KVM virtualization. Virtual CPU allocation does not mean ownership of a physical server or exclusive physical cores. Network uplink capacity does not guarantee a fixed speed to every destination.

## Manage your VPS

Use the [EDBB Control Panel](/vps-management/vps-control-panel) for service actions and [SSH](/linux-secure-shell-ssh) or [RDP](/windows-remote-desktop) to manage the operating system. Cloud-Init can configure a supported operating system on first boot. EDBB does not offer a customer or order API.
