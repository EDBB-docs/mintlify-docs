Find out how to connect to your VPS, manage it in the EDBB Control Panel and solve common problems. If you are new to EDBB, start with the four steps below.

## Set up your server

<Steps>
  <Step title="Find your service">
    Open the [EDBB Control Panel](https://my.edbb.com/clientarea.php) and select your VPS. Check the [welcome email](/check-your-inbox), assigned IP and installation status.
  </Step>
  <Step title="Connect">
    Use [SSH for Linux](/linux-secure-shell-ssh) or [Remote Desktop for Windows](/windows-remote-desktop). Keep the [VNC console](/vps-management/enable-vnc-server) available for recovery.
  </Step>
  <Step title="Secure access">
    Apply operating-system updates, configure permitted access and test a second login before removing the original access method. Follow [SSH hardening](/getting-started/ssh-security-hardening).
  </Step>
  <Step title="Arrange backups">
    Set up [independent backups](/backups) and test a restore before the server holds your only copy of important data.
  </Step>
</Steps>
